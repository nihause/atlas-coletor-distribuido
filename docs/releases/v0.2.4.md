Instaladores completos do Atlas Coletor, com interface gráfica e Python/Qt incluídos.

- **Windows 10/11 x64:** baixe `atlas-coletor_0.2.4_windows_amd64.exe`, execute e abra o Atlas pelo menu Iniciar. Instalação por usuário, sem precisar instalar Python.
- **Ubuntu 24.04 x64:** baixe `atlas-coletor_0.2.4_ubuntu24.04_amd64.deb` e abra no instalador de aplicativos.
- Configure URL `https://justisoft.com.br/radar/api/v1`, identificador e chave exclusivos deste computador criados no Radar. A chave pública DataJud já vem preenchida.
- Atualizações autenticadas por Ed25519 para cada plataforma, preservando configurações e aguardando as tarefas em execução. O manifesto Linux continua compatível com Atlas 0.2.2/0.2.3.
- Painel compacto com textos adaptados às fontes Windows. Inicialização automática na sessão é opcional.

O instalador Windows inicial não possui certificado Authenticode; o Windows pode mostrar aviso de editor desconhecido. Não há token GitHub necessário para baixar.

Validação: testes automatizados nos dois sistemas, auditoria de dependências e segredos; compilação, instalação, abertura da GUI empacotada, reinstalação e desinstalação em runner Windows. Não instalado no PC2 físico; nenhuma coleta de produção iniciada para testes.

Manual: https://github.com/nihause/atlas-coletor-distribuido/blob/main/docs/windows-linux.md
